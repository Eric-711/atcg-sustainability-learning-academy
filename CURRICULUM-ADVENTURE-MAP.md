# ATCG Curriculum Adventure Map — Initial Architecture

Status: PLANNING / PARTIAL ALIGNMENT. This is not a verified DPS unit-by-unit map.

## Authoritative sources
- DPS Central curriculum documents: https://central.dpsnc.net/home
- DPS curriculum and instruction: https://www.dpsnc.net/page/curriculum-and-instruction
- NC Standard Course of Study: https://www.dpi.nc.gov/districts-schools/classroom-resources/office-teaching-and-learning/standard-course-study
- Massachusetts DESE frameworks: https://www.doe.mass.edu/frameworks/current.html

## Rules for mapping
Every published activity must have grade band, subject, course, unit title, NC standard code and wording, MA framework code and wording (where applicable), source URL/document, verification date, learning objective, assessment evidence, accessibility alternatives, and game route. Never fabricate a code or district pacing sequence. Unverified mappings remain draft. Do not assume NC and MA standards are identical.

## Navigation
Grade band -> Subject -> Course -> DPS unit -> Standards -> Choose adventure -> Play -> Reflect -> Teacher review.
Grade bands: K-2, 3-5, 6-8, 9-12.
Subject catalog: English language arts, mathematics, science, social studies/history, world languages, arts, health/PE, computer science/digital literacy, career/technical education, English language development, student success. Availability differs by state and grade.

## Game genres
- Driving: road safety, proportional reasoning, physics, mapping, urban planning.
- Flying: forces and motion, weather, geography, navigation, measurement.
- Racing: graphing, speed and distance, statistics, optimization, teamwork.
- Sports: probability, anatomy, forces, data literacy, strategy.
- Community development: budgeting, ecology, civics, sustainability, land use, public services.
- Age-appropriate fictional combat: non-graphic robot-defense and strategy, evidence-based problem solving, cybersecurity; no realistic violence instruction.
- Escape rooms: reading comprehension, evidence, equations, science investigation.
- Survivor: resource management, ecosystems, weather, group decisions.
- Big Brother educational competitions: collaboration, debate, reasoning, quiz rounds.

## Delivery gates
1. Confirm authorized access to DPS Central maps and extract actual grade/course/unit sequence.
2. Extract exact NC standards and Massachusetts counterpart standards.
3. Have teacher review crosswalk; map each game to unit outcomes.
4. Build prototype in a separate GitHub route, do not change Base44 accounts/payments.
5. Test on mobile and desktop; check accessibility, data privacy, and actual game launch.
6. Integrate verified routes into navigation only after successful tests.

## Student privacy and safety
Do not collect student names, ages, school IDs, or personal chat histories without school-approved privacy controls. Avoid exposing API secrets. Keep fictional combat non-graphic and age-appropriate. Do not claim LMS/gradebook or multiplayer integration until implemented and tested.
